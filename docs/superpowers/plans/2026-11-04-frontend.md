# LabFlow Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a React frontend that matches the provided SVG and talks to the Java gateway for persons, materials, and borrow workflows.

**Architecture:** Vite dev server proxies `/api` to `localhost:8080`. A typed API layer unwraps the gateway `Result<T>` envelope. Pages use small `useResource` / `useMutation` hooks; no global state library.

**Tech Stack:** React 18, TypeScript, Vite, React Router, native CSS, Vitest, Testing Library, jsdom.

**Spec:** `docs/superpowers/specs/2026-11-04-frontend-design.md`

## Global Constraints

- No backend changes.
- All API calls go through `/api`.
- No UI framework, no Tailwind, no global state library.
- Currency/number formatting is not required; Chinese UI copy matches the SVG.
- Repository is not a git repo; skip commit steps.
- Node 22 / npm 12 are available.
